## Atlas の実装

### 共通ホスト

`app/components/task/ProjectTaskContextMenu.tsx` をプロジェクトページに1つマウントし、
document の `contextmenu` イベントから以下の属性を持つ最も近い要素をタスクとして解決する。

- `[data-list-row]`
- `[data-board-card]`
- `[data-timeline-bar]`
- `[data-calendar-multiday]`
- `[data-calendar-single]`

入力欄（`input` / `textarea` / `select` / `contenteditable`）上の右クリックは除外する。
メニューは body へのポータルで表示し、画面端では位置を補正する。

### メニュー項目

Asana と同じ並びで実装。

- タスクを複製: `POST /api/tasks/[id]/duplicate`
- フォローアップタスクを作成: `POST /api/tasks/[id]/follow-up`
- 完了にする / 未完了に戻す: 既存 `PATCH /api/tasks/[id]`
- サブタスクを追加: リスト・ボードのみ。既存 `POST /api/tasks`
- 変換先: ホバーまたはクリックでサブメニュー
  - タスク: `parent_task_id = null`, `is_milestone = false`
  - マイルストーン: `parent_task_id = null`, `is_milestone = true`
  - サブタスク: 親タスク選択ダイアログ（マイルストーンは解除）
  - 承認リクエスト: Atlas未対応のため無効表示
- タスクの詳細を開く: `?task=<id>` へ遷移
- 新しいタブで開く: 同じURLを新規タブで開く
- タスクのリンクをコピー: 失敗時は既存タスクペイン同様 `prompt` にフォールバック
- タスクを削除: 既存 `DELETE /api/tasks/[id]`

ボードの「カード画像を追加」は Atlas にカバー画像のモデルがないため未実装。

### 補足

- 権限がない場合（viewer）は参照系（詳細・新規タブ・リンクコピー）のみ表示。
- サブタスクへの変換候補から、自分自身と子孫タスクを除外して循環を防止。
- 複製は同一プロジェクト・セクション・親の位置に作成し、カスタムフィールド値もコピーする。
- フォローアップは同一プロジェクト・セクション・親に `フォローアップ: <元名>` として作成する。
- マイルストーンはトップレベルのタスクとして扱い、サブタスクへの変換時は解除する。
  リスト・ボード・タイムライン・カレンダー・タスクペインに金色の◆マーカーを表示する。

## マイルストーンとルール / オートメーション

- タスクに `is_milestone BOOLEAN NOT NULL DEFAULT FALSE` を追加。
- ルール条件 `task.is_milestone`（マイルストーン / 通常タスク）を追加。
- ルールトリガー `task.milestone_changed`（マイルストーンへの変換・解除）を追加。
- 変換時は `task.milestone_changed` ドメインイベントを発行し、条件・トリガーの両方で利用可能。
- AIルール提案でも「マイルストーン」を含むプロンプトから条件 / トリガーを生成する。
- 旧来の `project_automations` は条件式を持たないため変更なし。

## タイムライン上のマイルストーン / 単日タスク

AsanaのタイムラインをREAで観察し、以下を合わせた。

- マイルストーンは白いバーではなく、緑（`#46a75a`）の輪郭ひし形で表示。
- マイルストーンの日付には、キャンバス全高にわたる2pxの緑ラインを20%不透明度で表示。
- 開始日と期日が同一のタスク、期日のみ／開始日のみのタスク、マイルストーンは
  通常8px幅の細いバーで表示し、ホバー時に1日分の幅へ拡大する。
- 単日タスク・マイルストーンでは、右クリックしやすいよう完了チェックを表示しない。
- 細いバーの外側ラベルもホバー／右クリック領域に含め、ホバー時は透明化して
  バーの拡大を維持する。
- マイルストーンは期日（なければ開始日）の1日マーカーとして描画する。
- バーの縦ドラッグで行を固定でき、マイルストーンも任意の行に配置できる。
- 行固定中のタスクは右クリックメニューから「行の固定を解除」できる。

## タイムラインのレーン配置

Asanaと同様に、同一セクション内で日付範囲が干渉しないタスク／マイルストーンを
同じY座標のレーンに配置する。

- 日付範囲は開始日・期日を両端含みで判定する。
- マイルストーンは期日（なければ開始日）の1日範囲として扱う。
- 重なる場合は次のレーンへ配置し、セクションの高さは `レーン数 × 40px` になる。
- 左ペインのセクション高さ・スペーサーもレーン数に合わせる。
- 縦ドラッグの並べ替えは、ホバー中のレーンとX位置から挿入位置を決める。
- 例: 11/10–11 と 11/13–14 は同じレーン、11/10–11 と 11/10–11 は別レーン。
