## 1. Asanaホームの全体構造

### グローバルヘッダー

- 左上: サイドバー開閉、「＋ 作成」
- 中央: ワークスペース内検索
- 右: 「ダッシュで作業」（Dash / AI）
- ヘッダー下: ワークスペースのモード切替
  - 仕事 / エージェント / 戦略 / 知識 / ユーザー

### 左サイドバー

- ホーム / 受信トレイ / マイタスク / プロジェクト / ポートフォリオ
- お気に入り
- 仕事（プロジェクト一覧、もっと表示）
- 招待
- ヘルプ / ユーザー設定

### メイン領域

- 日付（例: `11月 9日 月曜日`）
- 挨拶（例: `Admin川田 さん、おはようございます`）
- 右側のホームコントロール
  - `週`（期間選択。選択肢は「週 / 月」を確認）
  - `完了済みのタスク`（完了タスクの表示切替）
  - `コラボレーター`（0人）
  - `＋ ウィジェットを追加`
- 2カラムのウィジェットグリッド
  - 各ウィジェットはカード型
  - ヘッダー、タブ、本文、フッター（もっと表示）、`…` メニュー
  - ウィジェットの追加・削除・サイズ変更が可能
  - 画面内に「新しいウィジェットをドラッグ & ドロップする」という追加枠がある

## 4. Atlasホームの現状

`app/page.tsx` は静的なサマリーページ。

- 日付・挨拶
- マイタスク / 受信トレイへの件数付きリンク
- 期限超過タスク一覧
- まもなく期限のタスク一覧
- プロジェクト一覧（カードグリッド）
- 新規プロジェクト作成
- プロジェクトテンプレート（テンプレートから作成 / 既存取込）

Atlasにある関連機能:
- `MyTasksView`（期限超過 / 今日 / 今週 / それ以降のバケット、DnD並び替え）
- プロジェクトダッシュボード（チャート / テキストウィジェット、並び替え、ウィジェット追加・編集）
- ポートフォリオページ（プロジェクト進捗・期限超過）
- 受信トレイ（コメント・イベント・メンション）

- プロジェクトメンバー / チーム管理
- カスタムフィールド、依存関係、タイムライン、カレンダー

Atlasにないもの:
- ワークスペース/ユーザー単位のホームウィジェットモデル
- ウィジェットの追加・削除・サイズ変更・並び替え・永続化
- ホームの期間 / 完了 / コラボレーターフィルタ
- ゴール（目標）ドメイン
- プロジェクトのステータス更新フィード
- 非公開メモ帳
- コメント下書き
- ミーティング
- Dash（AIアシスタント）
- ホームの「Asanaを学ぶ」的なオンボーディングウィジェット
- ウィジェット単位のタブ・空状態・「もっと表示」

## 6. 実装方針（Atlas向け）

### 6-1. ホーム専用ウィジェットモデル

プロジェクトダッシュボードの `project_dashboard_widgets` はプロジェクト単位・チャート/テキスト限定なので、ホームには流用せず、ワークスペース/ユーザー単位のモデルを追加する。

```sql
CREATE TABLE home_widgets (
  id BIGSERIAL PRIMARY KEY,
  workspace_id BIGINT NOT NULL REFERENCES workspaces(id),
  user_id BIGINT NOT NULL REFERENCES users(id),
  widget_type TEXT NOT NULL,
  config JSONB NOT NULL DEFAULT '{}'::jsonb,
  size TEXT NOT NULL DEFAULT 'half', -- half | full
  position INTEGER NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

- `widget_type`: `my_tasks`, `projects`, `assigned_tasks`, `members`, `portfolio`, `status_updates`, `notepad`, `comment_drafts`, `forms`, `meetings`, `mentions`, `dash`, `learn`
- 初期ユーザーにはAsana同等の5ウィジェットをシード
- 並び順・サイズを `PATCH /api/home/widgets` で保存
- ウィジェット追加・削除は `POST/DELETE /api/home/widgets`

### 6-2. ホームAPI

- `GET /api/home`（シェル + ウィジェット一覧 + 初期データ）
- `GET /api/home/widgets/:type/data`（ウィジェット単位の再取得）
- `POST/PATCH/DELETE /api/home/widgets...`
- サーバー側は `Promise.all` で初期データを並列取得。`React.cache` でユーザー/ワークスペースを共有。

### 6-3. UIコンポーネント

- `components/home/HomePage.tsx`
- `HomeHeader`（日付・挨拶・期間/完了/コラボレーター/ウィジェット追加）
- `HomeWidgetGrid`
- `HomeWidgetCard`（タイトル、タブ、メニュー、サイズ変更、削除）
- `AddWidgetDrawer`（カタログ + プレビュー + 追加）
- ウィジェット実装:
  - `MyTasksWidget`
  - `ProjectsWidget`
  - `AssignedTasksWidget`
  - `MembersWidget`
  - `PortfolioWidget`
  - `StatusUpdatesWidget`
  - `NotepadWidget`
  - `CommentDraftsWidget`
  - `FormsWidget`
  - `MentionsWidget`
  - `GoalsWidget`（ゴール導入後）
  - `MeetingsWidget` / `DashWidget` / `LearnWidget`（P2）

### 6-4. 既存資産の再利用

- `MyTasksView` のバケット計算（期限超過 / 今日 / 今週 / それ以降）を `lib/my-tasks.ts` に抽出して共用
- `my_task_orders` の並び順をマイタスクウィジェットでも利用
- `getProjectsForUser` / `getProjectStats` / `ProjectIcon` をプロジェクトカードに利用
- `getPortfolio` をポートフォリオウィジェットに利用
- `getProjectMembers` / `getUsers` をメンバーウィジェットに利用
- `getInbox` / `getUnreadCount` をメンションウィジェットに利用
- `project_forms` をフォームウィジェットに利用
- プロジェクトダッシュボードの `WidgetDialog` / `ChartRenderer` はホームのチャートウィジェットには再利用可能。ただしホーム用の設定UIは別途必要

### 6-5. ウィジェット共通UX

- ヘッダー: アイコン、タイトル、ロック、`…`
- `…` メニュー: 作成系アクション / すべて表示 / ハーフサイズ / フルサイズ / 削除
- タブ: ウィジェットごとのバケット
- 空状態: アイコン、説明、主要アクション
- フッター: `もっと表示`
- 追加枠: 破線カード「ウィジェットを追加」
- 2カラム、狭幅は1カラム。ハーフ/フルサイズで幅を制御
- ドラッグ & ドロップ並び替え。キーボード代替も用意

## 8. 注意点・未確認事項

- Asanaのウィジェットメニューは「マイタスク」で確認。他のウィジェットも同様のサイズ/削除メニューを持つと見られるが、全ウィジェットで個別確認はしていない。
- ドラッグ & ドロップによる並び替えは、画面上の追加枠とサイズメニューから存在を確認。実際のドラッグ操作・並び順の永続化仕様は未検証。
- ウィジェットごとのデータ取得API・キャッシュ戦略は未調査。UI構造からの推定を含む。
- Asanaのワークスペース設定・プランにより、表示されるウィジェットやDashの有無は変わり得る。
- Atlasのゴール、ステータス更新、メモ帳、ミーティング、Dashは新規ドメインが必要で、単なるUI追加では済まない。
