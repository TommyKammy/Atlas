# Atlas × Asana パリティ詳細テスト計画

作成日: 2026-11-06  
目的: REA で Asana の実挙動を観測し、Atlas との差分を「一致 / 部分一致 / 差分 / 未実装 / 対象外」で分類する。  
対象: Atlas のプロジェクト管理 UI 全体。まずはテスト項目を固定し、次フェーズで優先度順に実行する。

## 1. テスト環境

- Asana: `Test_PJ`（project `1220280937815000`）を主対象にする。
  - 通常は読み取り専用。
  - 追加・削除・並び替えが必要な項目のみ、Test_PJ 内で実施して必ず後始末する。
- Atlas: `http://127.0.0.1:3000`
  - 管理者: `admin@example.com` / `atlas-dev-2026`
  - DB: `docker exec atlas-db psql -U atlas -d atlas`
  - API/DB の確認を併用する。
- ロール検証用: 管理者 / 編集者 / コメンター / 閲覧者 / ゲスト。
- 画面幅: 1920×1080、1440×900、1024×768、390×844。
- ブラウザ: Chrome。必要に応じて Safari 相当の差分も確認する。

## 2. テストデータ

破壊的テストの前に DB バックアップを取得する。Atlas 側は一時プロジェクトを作成し、終了後に削除する。

| データ | 内容 |
|---|---|
| セクション | 4つ以上。空セクション、折りたたみ対象を含む |
| 通常タスク | 開始日と期日が異なる |
| 1日タスク | `start_on === due_on` |
| 期日のみ | 開始日なし、期日あり |
| 日付なし | 開始日・期日ともなし |
| 完了タスク | 完了済み、進捗100% |
| 長い名前 | 日本語20文字以上、英数字、絵文字 |
| 担当者 | 割当あり、未割当、ゲスト |
| サブタスク | 2件以上、親タスクあり |
| 依存関係 | A → B、循環候補 |
| カスタムフィールド | テキスト、数値、単一選択 |
| Status | 3つ以上の選択肢 |
| テンプレート | サブタスク・担当者・期日オフセット付き |
| 共有 | 共有リンク、プロジェクトメンバー |

## 3. 証跡と記録方法

- Asana: REA の `capture_web_screenshot`、DOM 計測、trusted mouse、必要なら network capture。
- Atlas: REA/CDP、API レスポンス、DB クエリ、`tests/e2e.sh`。
- 各項目に以下を記録する。

| 項目 | 内容 |
|---|---|
| Asana evidence | `ev_...` |
| Atlas evidence | `ev_...` / screenshot path / DB結果 |
| 結果 | 一致 / 部分一致 / 差分 / 未実装 / 対象外 |
| 重要度 | S1 致命的 / S2 大 / S3 中 / S4 軽微 |
| 修正候補 | 実装・文言・余白・挙動など |
