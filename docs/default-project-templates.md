# Atlas 標準プロジェクトテンプレート

Asana の人気テンプレートを参考に、Atlas で標準提供するプロジェクトテンプレート。

## 方式

- 定義は `lib/default-project-templates.ts` のコードで管理
- `project_templates` テーブルに `is_builtin` / `builtin_key` / `category` を追加
- テンプレートギャラリーを開いたタイミングで、ワークスペースごとに自動シード
- `ON CONFLICT (workspace_id, builtin_key)` で定義変更時は内容を更新
- 標準テンプレートは削除不可（API/UI とも保護）
- ユーザーが保存したテンプレートとは区別し、ギャラリーでは「Atlas おすすめテンプレート」に表示

## UI

- テンプレートギャラリーに「Atlas おすすめテンプレート」セクションを追加
- カテゴリフィルタ（プロジェクト管理 / エンジニアリング / マーケティング / オペレーション / 人材 / 生産性）
- テンプレート検索の対象に標準テンプレートを含める
- 標準テンプレートのカードには「Atlas標準・カテゴリ」を表示
- 詳細画面ではセクション、タスク例、作成者に代えて「Atlas標準テンプレート」を表示
- 標準テンプレートには削除ボタンを表示しない

## 作成時の挙動

既存の `POST /api/project-templates/[id]` をそのまま利用する。
標準テンプレートも `project_templates` の1行としてシードされるため、通常のテンプレートと同じようにセクション・タスク・サブタスク・期日オフセットがコピーされる。

## 検証

- 12テンプレートの自動シード
- カテゴリフィルタと検索
- 標準テンプレートから3セクション・10タスク（サブタスク3件）のプロジェクト作成
- 標準テンプレートの削除APIが403
- ユーザーテンプレートの作成・削除は従来どおり
- E2E 587件 PASS
