# ダッシュボードからリストへの絞り込み

ダッシュボードの数値、棒の各区分、ドーナツの区分・凡例・中央の合計、折れ線・バーンアップ・バーンダウンの点から、同じプロジェクトの通常リストを開けます。「すべて表示」はウィジェット全体の対象タスクを開きます。ゼロ値や重なった点も「データを表示」の表から選択できます。リンクは閲覧者も利用でき、キーボード操作や別タブで開く操作に対応します。

## 集計条件

- URL の `dashboard` パラメーターは、ウィジェットの条件・指標・区分・系列・集計基準日を持つバージョン付き JSON です。タスク ID の配列や表示ラベルを検索条件として使いません。
- 数値はウィジェットの条件と指標を AND で評価します。たとえば完了数から開くリストは完了タスクだけです。進捗の合計・平均は、その値に寄与したタスクを表示するため、数値とリストの件数は一致しません。
- 積み上げ・グループ化された棒は、選んだ区分に加えて未完了／完了の系列を引き継ぎます。区分はセクション・担当者の ID や未設定値で識別し、同名の項目を混同しません。
- 時系列は省略表示の月日ではなく完全な ISO 日付を引き継ぎます。合計はその日までに作成されたタスク、完了はその日までに完了したタスク、残りはその日までに作成され、その日には未完了だったタスクです。履歴スナップショットではないため、削除や現在のウィジェット条件に関わる変更があれば対象集合は変わります。
- 今日・期限超過・今後の期間はリンク生成時の JST 日付を基準にします。ダッシュボード既存仕様の「今後 1 週間」は基準日から 7 日後まで、「今後 1 か月」は 30 日後までを含みます。通常リストの相対日付フィルターには置き換えません。
- 集計対象は既存のダッシュボードと同じ主タスクです。サブタスクは初期状態で閉じます。マルチホームのセクションは、表示中プロジェクトに所属するセクションを使います。

## 通常リストとの関係

リスト上部に元のウィジェット名・固定条件・元の集計対象件数を表示します。リストの操作で条件を追加しても、この元の対象集合が上限です。ブラウザの戻る／進むでも追加条件に一覧が追従し、タスク詳細を閉じた際にも集計条件と追加条件を保持します。「ダッシュボードへ戻る」で再び集計を選択でき、「通常のリストに戻る」で通常の保存設定に戻れます。

集計から開く際には、通常リストの保存済みフィルターと保存済みビューを混ぜません。この一時表示中の操作は通常リストの表示設定へ保存しません。また、固定条件を通常の保存済みビュー形式では表現できないため、一時表示中は「ビューを保存」を無効にします。タスクの編集権限は従来どおりです。

## 入力と認可

URL は最大 4,096 文字、既知のキー・列挙値、正の安全な整数 ID、実在する ISO 日付／月、チャートと区分・系列の整合性を検証します。不正な条件では警告と空のリストを表示し、全件表示には戻しません。

プロジェクトの認証・認可を先に実施し、既存の認可されたリストとダッシュボードのプロジェクトスコープ内でのみ絞り込みます。URL を編集しても別プロジェクトのタスクを追加取得することはありません。スキーマ変更・マイグレーションはありません。

## 回帰テスト

- `lib/dashboard-drilldown.test.ts`: 指標・複合条件・各区分・系列・時系列・日付境界・同名／未設定項目・URL 検証。
- `lib/dashboard-renderer.test.ts`: ネイティブリンク、ゼロ値、ドーナツの区分対応、積み上げ軸、プレビューの後方互換。
- `lib/task-pane-navigation.test.ts`: タスク詳細を閉じた際の集計・追加条件保持、不正条件の空表示保持、通常ビューの互換性。
- `tests/browser/dashboard-drilldown.spec.ts`: 実際のクリック遷移、対象行、通常設定の保護、閲覧者・キーボード、空表示、不正入力、マルチホーム。

ブラウザテストは `bash tests/run-e2e.sh browser` の生成するガード付き使い捨て環境で実行します。既存環境向けの URL を直接渡して実行しません。
