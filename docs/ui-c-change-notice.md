# Atlas 新UI 変更のご案内

Atlas の画面を、社内で承認された新しいデザイン（C 案「workbench」）に更新しました。この文書は、日々 Atlas を使う方に向けた変更点のまとめです。

## 何が変わったか

- **見た目の方針**: 装飾を減らし、限られた画面に必要な情報を詰めて表示する方針になりました。画面名は 15px の太字、説明は 13px の補助色、本文は 13px を基本とし、フォームの入力欄と主なボタンは 32px、リストの行は 38px の高さに揃えています。
- **配色**: 色を意味ごとの共通トークンにまとめ、アクセントは 1 色にしました。ライトは白地に黒系のアクセント、ダークは暗い地にライム系のアクセントです。成功・注意・エラーは色だけでなく、文字のラベルやアイコンも組み合わせて示します。
- **ライト / ダーク**: どちらも正式にサポートしています。既定はライトです。OS の設定には自動で追従せず、サイドバー下部（サイドバーが隠れる狭い画面では上部バーの右端）で選びます。
- **情報の密度**: カードの影を減らし、罫線と余白で区切るようにしました。タスクの一覧、ボード、タイムライン、カレンダー、ダッシュボードは同じデータを使ったまま、表示を刷新しました。

## 場所が変わったもの・名前が変わったもの

| 項目 | 変更前 | 変更後 |
|---|---|---|
| 検索 | 画面上部のヘッダーにあった検索ボックス | サイドバー上部の「検索」、または ⌘K / Ctrl+K のコマンドパレット |
| 作成 | 画面上部のヘッダーの作成メニュー | サイドバー上部の「作成」（狭い画面では上部バー） |
| テーマの切り替え | 画面上部のヘッダー | サイドバー下部（狭い画面では上部バーの右端）の太陽 / 月のアイコン |
| サイドバー | 折りたたみ用のアイコン列と、展開時のパネルが分かれていた | 展開時は 1 枚のパネルにまとまり、上部に作成と検索、下部にテーマ・ヘルプ・ユーザーメニュー。狭い画面では上部バーの右端にテーマとヘルプ |
| プロジェクトのタブ | プロジェクト名の下に別の行で表示 | プロジェクト名と同じ行（狭い画面では下の行）。デスクトップ幅で収まらないタブは右端の「その他」にまとまる |
| タスク詳細 | 右側の広いペイン（画面幅に応じて 560〜760px） | 右側のペイン（中程度の幅で 480px、広い画面で 440px）。狭い画面では画面全体に重なる |
| マイルストーンの読み上げ | クリティカルでも「マイルストーン」 | クリティカルパス上は「クリティカルパス上のマイルストーン」 |

## 新しくできるようになったこと

- **コマンドパレット**: ⌘K / Ctrl+K で、検索と画面移動を 1 か所から行えます。タスク、プロジェクト、メッセージ、知識、ファイルを検索し、候補を選ぶとその画面へ移動します。「すべての結果で検索」から検索画面も開けます。
- **j / k での行移動**: リストのタスク行を j（次）/ k（前）で移動できます。これまでの ↑ / ↓ も使えます。
- **日本語入力中の誤動作防止**: 入力欄の編集中や日本語変換中は、1 文字のショートカット（j / k、g の後に続くキー、?、n など）が動かなくなりました。タスク名や説明に「g」「b」と入力しても画面が切り替わりません。
- **ホームの概要**: ホーム上部に、今日の件数、期限超過、今週の予定、最近開いたプロジェクトの進み具合、受信トレイ、決裁待ちがまとまりました。決裁待ちには、自分が開く権限を持つ提案だけが表示されます。
- **ボードの「要対応」**: ボードのツールバーで、期限超過の未完了タスクだけを表示できます。
- **狭い画面での改善**: 375px 幅でもポートフォリオの表が画面全体を広げず、表の中でスクロールします。これまでホバーでしか出なかった操作（列メニュー、行やサブタスクの削除、コメントの編集・削除、タイムラインの依存関係ハンドル）がキーボードのフォーカスでも表示されます。
- **期限の手がかり**: 期限超過には警告の形と「期限超過」、今日が期日には時計の形と「今日が期日」が付きました。クリティカルパス上のマイルストーンには、専用の読み上げ名が付きました。

## 変わらないもの

- **データ**: 既存のプロジェクト、タスク、コメント、ノート、添付ファイルはそのまま残ります。この更新ではデータベースの構造と API を変更していません。
- **権限**: 閲覧・編集・管理者などの権限の内容は変わりません。ポートフォリオの入口は、閲覧権限がある人だけに表示されるようになりましたが、権限の付与条件自体は同じです。
- **URL**: 画面の URL は変わりません。プロジェクトの `?view=...&tab=...` を含め、これまでのブックマークをそのまま使えます。
- **基本操作**: タスクの作成・編集、コメント、添付、プロジェクトの設定など、これまでの操作手順はそのまま使えます。

## 既知の制限

- OS のライト / ダーク設定には自動で追従しません。テーマはサイドバー下部、サイドバーが隠れる狭い画面では上部バーの右端で選びます。
- プロジェクト設定の通知にある Slack / Microsoft Teams の外部チャンネル連携は未接続です。接続設定は今後追加されます。カスタマイズの「アプリ」から追加する Slack、Google Drive、GitHub、Webhook とは別の機能です。
- ライトテーマでは、装飾用のごく薄い文字（鍵アイコン、ドラッグハンドル、開閉の矢印など）が WCAG AA のコントラスト基準を満たしていません。本文や操作ラベルには使っていません。
- タイムラインのクリティカルパスは日程の強調表示です。人員や容量を考慮した再スケジュールや、開始日・終了日の自動調整は行いません。
